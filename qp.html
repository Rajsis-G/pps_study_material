🔢 Fibonacci Series
Generate n terms where each term = sum of previous two
💡
What is Fibonacci?
  • Each new term = sum of the previous two terms
  • The series starts with 0 and 1
  • Example: 0, 1, 1, 2, 3, 5, 8, 13, ...
💻
C Program
#include <stdio.h>
int main()
{
    int n, i, a = 0, b = 1, c;
    printf("Enter the value of n: ");
    scanf("%d", &n);
    printf("Fibonacci Series: ");
    for(i = 1; i <= n; i++)
    {
        printf("%d ", a);  // print current term
        c = a + b;              // next = prev1 + prev2
        a = b;                  // slide forward
        b = c;
    }
    return 0;
}
Key Variables
  • a = 0 — first Fibonacci term
  • b = 1 — second Fibonacci term
  • c = a + b — calculates the next term
  • After each step: a = b and b = c to move forward

Algorithm
  1. Start
  2. Read n
  3. Set a = 0, b = 1
  4. Repeat from i = 1 to n
  5. Print a
  6. Compute c = a + b
  7. Update a = b and b = c
  8. Stop
🔁 Loop Comparison
for · while · do-while — syntax, examples, and differences
for loop
  • Best when number of iterations is known
  • Init, condition, update all in one line
  • Entry-controlled — condition checked first
  • May execute zero times
for(init; condition; update)
{
    statements;
}
while loop
  • Best when iterations are not fixed
  • Condition checked before body executes
  • Entry-controlled loop
  • May execute zero times
while(condition)
{
    statements;
}
🔵
do-while loop
  • Condition is checked after the body — exit-controlled
  • Runs at least once even if condition is false initially
  • Use when the code must execute at least one time
do
{
    statements;
}
while(condition);

All Three — Printing 1 to 5

while(i <= 5)  { printf("%d ", i); i++; }

❓ Ternary Operator
A compact conditional — short form of if-else
💡
What is it?
  • Called ternary because it takes three operands
  • Acts as a compact replacement for a simple if-else
  • Makes programs shorter and more readable for simple decisions
📐
Syntax & Working
// Syntax
condition ? expression1 : expression2;

// If condition is TRUE  → expression1 executes
// If condition is FALSE → expression2 executes
condition
→
TRUE → expr1
|
FALSE → expr2
💻
Example — Find Maximum
#include <stdio.h>
int main()
{
    int a = 10, b = 20, max;
    max = (a > b) ? a : b;  // a>b is FALSE, so b=20 assigned
    printf("Maximum = %d", max);
    return 0;
}
// Output: Maximum = 20
Trace
  • Condition: (a > b) → (10 > 20) → FALSE
  • Since FALSE → expression2 (b) is evaluated
  • Result: max = 20
⚖️
Ternary vs if-else
Ternaryif-else equivalent
max = (a>b) ? a : b; if(a>b) max=a;
else max=b;
  • Ternary is more concise — fits in one line
  • Best for simple 2-choice decisions only
  • Avoid nesting ternary operators — reduces readability
🔄 Reverse a Number
Extract digits one by one using % and / to build the reverse
💡
Core Idea
  • num % 10 → gives the last digit
  • rev = rev * 10 + rem → appends digit to reverse
  • num / 10 → removes the last digit
  • Repeat until num == 0
💻
C Program
#include <stdio.h>
int main()
{
    int num, temp, rem, rev = 0;
    printf("Enter a number: ");
    scanf("%d", &num);
    temp = num;
    while(temp != 0)
    {
        rem = temp % 10;        // extract last digit
        rev = rev * 10 + rem;   // build reverse
        temp = temp / 10;       // remove last digit
    }
    printf("Reverse = %d", rev);
    return 0;
}

💾 Computer Hardware
CPU · RAM · ROM · Hard Disk · Volatile vs Non-volatile
CPU
  • Brain of the computer
  • Performs all calculations and logical operations
  • Controls and coordinates all other parts
RAM
  • Primary / working memory
  • Stores data temporarily while processing
  • Volatile — data lost when power off
ROM
  • Stores permanent startup / boot instructions
  • Non-volatile — retains data without power
  • Read-only — cannot be easily modified
Hard Disk
  • Secondary storage for permanent data
  • Stores OS, programs, files, documents
  • Non-volatile — data persists after shutdown
⚡

Quick Summary
  • CPU — processes data
  • RAM — stores data temporarily (volatile)
  • ROM — stores fixed boot instructions (non-volatile)
  • Hard Disk — stores everything permanently (non-volatile)
